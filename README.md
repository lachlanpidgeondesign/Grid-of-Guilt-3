
  # Grid of Guilt #3

  This is a code bundle for Grid of Guilt #3. The original project is available at https://www.figma.com/design/3FI0CYFq7HlYUqFB8OiVFu/Grid-of-Guilt--3.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploying to GitHub Pages

  This project is configured to deploy automatically with GitHub Actions when you push to `main`.

  1. In GitHub, open Settings -> Pages.
  2. Set Source to GitHub Actions.
  3. Push to `main`.

  The site will be available at:

  https://lachlanpidgeondesign.github.io/Grid-of-Guilt-3/
